## 🔬 Research & Projects

### ⚛️ Model-Independent Anomaly Detection for Semi-Visible Jets
**Bachelor's Thesis — ATLAS Open Data**

A machine-learning-based search for **non-resonant semi-visible jets** arising from hidden-sector physics. The analysis explores **Classification Without Labels (CWoLa)**, background estimation, and anomaly detection using ATLAS Open Data.

**Key technologies:** PyTorch · XGBoost · ROOT · Python · pyhf · Awkward Array · Polars · NumPy · SciPy

### 👨‍🔬 CERN Summer Student 2025
**Leveraging Forward Flavour Tagging for bbH Studies in ATLAS at the HL-LHC**

Research project focused on exploiting **forward flavour-tagging techniques** for Higgs studies in the ATLAS experiment at the High-Luminosity LHC.

**Key technologies:** C++ · Python · ROOT · ATLAS software · Monte Carlo simulation

### 🧪 Collider Phenomenology & Monte Carlo Simulation

Experience with particle-physics simulation and analysis workflows, including **MadGraph5_aMC@NLO**, **Pythia8**, **Delphes**, **FastJet**, and **Rivet** for studying BSM phenomenology and collider signatures.
